# T-005 — Unified Policy Executor, File Safety and Bounded Command Execution

**Phase:** 1 — Agent Foundation & Safety
**Depends on:** T-003, T-004
**Sources:** spec.md sections 17, 33–34, 38; handoff.md sections 5.4, 12

## Goal
Ensure every executable/read/write path uses one policy, journaling, cancellation and output-bounding pipeline.

## Scope
Implement Policy Executor for Pi built-ins, custom tools and approved extensions. Support read, workspace edit, trusted test/build, external-effect and destructive-action classifications.

For file changes: resolve real paths, reject traversal and symlink escape, protect .macus internal state from generic edits, record read-before-edit hash, compare the hash immediately before atomic write, preserve relevant permissions and classify changes as agent, pre_existing or external_or_unknown.

For commands: explicit cwd/args or shell command, timeout, cancellation signal, process-group termination with bounded grace, environment allowlist and model-credential removal by default.

For output: max 8 MiB memory buffer, max 100 MiB spool per execution, bounded model-facing result, redaction, unsafe terminal-control stripping, opaque bounded read_log references and default 7-day / 1-GiB aggregate retention.

## Acceptance Criteria
- [ ] No Pi bash/write path bypasses policy, journal or output limits.
- [ ] Intervening external edit causes hash conflict and recomputation.
- [ ] Timeout/cancel records outcome fields truthfully.
- [ ] Unknown side effects are never auto-replayed.
- [ ] Credentials are excluded from subprocess environment unless authorized.
- [ ] No automatic reset, clean, force push, rollback, commit, push, merge or publish.
- [ ] Large output cannot exhaust memory.
- [ ] Expired/missing log references return explicit errors.

## Tests
Large output, symlink escape, hash mismatch, cancellation, timeout, secret redaction, state-path protection and unknown side effects.
