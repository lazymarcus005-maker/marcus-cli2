# T-007 — Phase 1 CLI, Session UX and Manual Compaction

**Phase:** 1 — Agent Foundation & Safety
**Depends on:** T-002, T-003, T-004, T-006
**Sources:** spec.md sections 21, 26–29, 43; handoff.md section 11

## Goal
Deliver the first usable branded macus interactive CLI on top of the verified kernel and core safety/state layers.

## Scope
Implement the macus executable, interactive launch, initial prompt mode, streaming terminal output, Ctrl-C cancellation and graceful exit.

Commands required now: /help, /status, /exit, /model, /models, /settings, /resume [id], /clear, /compact and basic /context.

Semantics:
- /clear creates a new session without deleting code or prior sessions.
- /resume validates worktree identity and journal before mutation.
- /model selects only trusted aliases and forces budget revalidation.
- /compact uses Pi-supported compaction at a safe boundary and validates the resulting request.
- Status only shows values that are available and truthful.

## Acceptance Criteria
- [ ] Branding is Macus Code / macus.
- [ ] Streaming is incremental.
- [ ] Ctrl-C propagates cancellation and persists observed outcome.
- [ ] Unsupported/disabled commands return clear unavailable status.
- [ ] /settings redacts secrets.
- [ ] /context distinguishes last dispatched request from next-request estimate.
- [ ] No noninteractive CI mode is implied.
- [ ] Manual compaction cannot discard unresolved tool obligations.

## Tests
CLI commands, session switching, cancellation, model switch validation, clear/resume behavior and compact failure/cancellation.
