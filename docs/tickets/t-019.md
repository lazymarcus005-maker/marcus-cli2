# T-019 — Coordinated Compaction, Stage-Aware Context and Phase 5 Gate

**Phase:** 5 — Durable Context & Optimization
**Depends on:** T-006, T-018
**Sources:** spec.md sections 6.6, 21–22, 31, 45; handoff.md sections 9–10

## Goal
Coordinate full compaction with durable state and request budgeting while preserving protocol validity and task intent.

## Scope
At a safe tool boundary: commit current task/ledger state, create a checkpoint when enabled, invoke Pi-supported compaction, validate the resulting effective request, then continue only when the budget invariant holds.

Preserve goal/constraints, current task, decisions, working file versions, diff awareness, unresolved failures, pending work, next action and unknown executions.

Serialize compaction with model dispatch and session replacement. Ensure there is one automatic compaction trigger authority. Manual compact remains available when auto_compaction is disabled. Compaction requests are themselves budgeted and measured.

Apply deterministic stage-aware context priorities and prompt-cache-friendly byte stability where practical, without reordering chronological/protocol messages.

Create docs/phase-5-evidence.md.

## Acceptance Criteria
- [ ] Goal, constraints and unresolved tool obligations survive compaction.
- [ ] Compaction failure/cancellation preserves a usable previous state and pauses safely.
- [ ] Checkpoint failure blocks compaction when checkpoint feature is enabled.
- [ ] Disabling auto compaction does not disable the request budget guard.
- [ ] No second independent compaction engine competes with Pi.
- [ ] Provider cache metrics are shown only when reported/measured with denominator.
- [ ] Checkpoint restore invalidates stale evidence without source rollback.
- [ ] Supported feature-flag combinations are tested.
- [ ] Common phase gate tests/typecheck/build/lint and CLI verification are recorded.

## Evidence
Capture pre/post compaction manifests, checkpoint/state revision, failure and cancellation cases, plus supported feature combinations.
