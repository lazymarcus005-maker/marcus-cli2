# T-001 — Repository Bootstrap and Implementation Map

**Phase:** Pre-Phase 1
**Depends on:** none
**Sources:** spec.md Document Contract, sections 1–4, 41, 45; handoff.md sections 1–3, 16

## Goal
Prepare the repository for implementation without inventing existing architecture or overwriting user work.

## Scope
- Confirm canonical spec.md and handoff.md are Version 1.1.
- Inspect repository root, Git/worktree identity, status, staged/unstaged/untracked files, instructions, package/runtime manifests and existing source/tests.
- If the repository is effectively empty, create only the minimum Node/TypeScript scaffold required by the specification.
- Select and pin one Node LTS runtime and one package manager with lockfile.
- Record existing or absent Pi integration, CLI/TUI structure, test/build/lint/typecheck commands and CI configuration.
- Create docs/implementation-map.md mapping specification sections and phase gates to modules/files.
- Create an implementation TODO list ordered by Phase 1–7.

## Requirements
Preserve all unrelated user changes. Do not overwrite a different specification blindly. Do not add Docker, vector DB, graph server, cloud service, background daemon or monorepo complexity without a demonstrated requirement.

## Deliverables
Minimal project scaffold where needed; runtime/package-manager pins; docs/implementation-map.md; initial TODO/phase mapping; repository assessment notes.

## Acceptance Criteria
- [ ] Canonical spec/handoff pair verified as v1.1.
- [ ] Git/worktree and existing changes recorded.
- [ ] Existing architecture and commands documented accurately.
- [ ] Minimal scaffold builds without out-of-scope infrastructure.
- [ ] Every phase has an implementation owner/module mapping.
- [ ] No unrelated file is modified or removed.

## Evidence
Record exact inspection/build commands, repository revision/worktree identity, runtime/package-manager versions and resulting file paths.

## Out of Scope
Feature implementation, Pi API claims, production-readiness claims, commit/push/publish.
